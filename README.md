# Mercer's Pyramid Texts

⬇️ [`_download.py`](_download.py) downloads *Samuel A. B. Mercer's* translation of the *pyramid texts* from [sacred-texts.com](https://sacred-texts.com/egy/pyt/index.htm) to the [`utterances`](utterances) directory.\
Each utterance is stored in a separate file, named [`001.txt`](utterances/001.txt) through [`714.txt`](utterances/714.txt).

✨ The download script was written with the help AI and I didn't put much effort into verifying the script or the output it produced.
